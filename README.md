# How to modify this project

1. Only the **prod** branch can affect the online website. It is protected and can only be modified by creating a pull request.
2. Once the pull request is merged into **prod** branch, the website will be automatically updated.
3. You can take a look at the preview version of the website when you create a pull request, which is automatically generated by Netlify.
